# sev-znc-libs

My ZNC Libraries
----------------

These libraries are for  the znc compiler on the 
ZX Spectrum Next.

Copy theses files to your /znc folder on your ZX 
Spectrum Next, or run install.bas on your Next 
which does exactly that if you have cloned or 
unzipped this repository to you SD Card.

- datetime.vnc - v0.0.2 (11-Oct-2025)
- joystick.znc - v0.0.4 (05-Oct-2025)
- mouse.vnc    - v0.0.2 (29-Sep-2025)
- version.znc  - v0.0.1 (23-Sep-2025)

The library folders also contains test programmes 
and a ZX Spectrum BASIC programme that will build 
the test programmes into .nex files that will 
run on the Next.

The library folders also contain older versions of 
each library, so you can see the evolution of the 
libraries.
